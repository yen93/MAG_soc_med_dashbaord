BUG FOUND AND FIXED (js/scoring.js)
--------------------------------------
Once real-but-partial data started flowing through the engine, a latent bug
surfaced: scoreInstagram/scoreFacebook/scoreLinkedin's engagement-rate
calculations gated only on `isNum(raw.followers)`, then defaulted every
missing per-post metric to 0 *inside* the numerator via `?? 0`. Concretely:
a real follower count with no per-post engagement data produced a
confidently wrong "0% engagement rate -> At Risk" instead of "No Data" —
worse than the placeholder data it was replacing, since it looks like a
real, bad measurement rather than an absent one. Fixed by requiring at
least one real engagement-volume field (avgLikesPerPost/avgCommentsPerPost
for Instagram & LinkedIn; also avgSharesPerPost for Facebook) before
computing a rate at all; otherwise the category now correctly resolves to
null / "No Data". This is the only change made to scoring.js's formulas —
weights and benchmarks are untouched.

A SECOND ISSUE THIS SURFACED (fixed in js/app.js, not scoring.js)
---------------------------------------------------------------------
Running the real, sparse data through computeAllScores() showed something
the scoring model's weight-renormalization design doesn't protect against:
a channel with only 1 of 5 categories scored can land on "100/100,
Excellent" — indistinguishable in the UI from a channel that's fully
measured and genuinely excellent. (Instagram and LinkedIn both hit this:
each currently has only "profile/page completeness" filled in, both scored
100, so both show "Excellent" today with 4 of 5 categories blank.) Asked
the user how to handle it; chose to add a coverage indicator rather than
change the scoring formula. js/app.js now renders a "N of 5 categories
scored" chip next to every grade badge (hero score aggregates across all 4
channels: today that's "6 of 20 categories scored") via two new helpers,
coverageFor() and aggregateCoverage(). The underlying scores/grades are
unchanged — this only adds visible context so a sparse "Excellent" is never
mistaken for a comprehensive one.
